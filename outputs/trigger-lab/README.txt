差一点就断了 / 2D MPV 刹车小实验

游戏：http://127.0.0.1:8765/
原扳机实验室：http://127.0.0.1:8765/lab/

如服务器已关闭，在本目录运行：
python3 -m http.server 8765 --bind 127.0.0.1

操作：
- 普通 DualSense USB：在标题画面打开手柄设置，授权后轻按 R2；可分别测试震动和阻力，返回标题后开始驾驶。
- R2 直接控制刹车行程；行驶时同时输出阻力与震动。
- 键盘：按住空格逐渐加压，松开逐渐回弹。
- 触屏 / 鼠标：按住屏幕刹车按钮。
- Esc 暂停并释放手柄效果；Enter 在开始或结算画面开新一局。
- 切到后台自动暂停；关闭页面时异步释放只能尽力发送。

玩法：从 100 km/h 开始，踏板完好地停住，距离越短越好。
超过 86% 行程会积累损伤，退回安全区只停止继续损伤，耐久不会恢复；新一局重置。
踏板断裂时有特写、合成断裂音效，立即结束本局并显示游戏失败，不显示或记录本局成绩。
断裂成绩不计入个人最佳。最佳成绩只存储在浏览器本地。

所有车辆、外观与物理参数均为虚构。不代表真实车辆或驾驶行为。
无服务器数据收集、无第三方脚本。声音由 Web Audio 合成。
首版手柄支持普通 DualSense USB，不支持蓝牙 / Edge。
协议参考：https://github.com/nondebug/dualsense

第三版：路边新增近景树列；踏板承受损伤降至初版的 1/5（过载损伤速度五倍，86% 边界不变）。
从零损伤开始，全压约 0.13 秒断裂，90% 约 0.455 秒断裂。
设置页新增独立刹车音效开关，偏好存储在本地；其他音效仍由总声音开关控制。

节奏更新：减速度倍率 0.6，积分距离倍率 0.85；画面按倍率反算位移，保持高速观感。
80% 持续刹车约 5.2 秒、61.3 个游戏米。新倍率最佳成绩使用独立本地存储，旧成绩保留但不混比。
刹车音效为摩擦噪声、谐波尖啸与不规则颤动的合成效果。

通用手柄：Gamepad API 自动发现浏览器支持的 XInput / DInput 设备；需先按手柄按键。
标准映射默认按键 7（RT / R2）。非标准映射可选轴或按键并校准两端，支持反向轴和数字键渐进模式。
不直接调用 Windows DInput / XInput 驱动，实际支持范围取决于系统和浏览器。震动按运行时能力检测。
